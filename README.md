## 📌 About the Project

**WebLab Practical** is an interactive academic web laboratory designed to demonstrate and organize practical programs based on **HTML, CSS, and JavaScript**.

Instead of keeping practical programs as separate static files, this project brings them together into a **searchable, responsive, and interactive web interface**.

The project contains:

* 📄 HTML practical programs
* 🎨 CSS experiments
* ⚡ JavaScript experiments
* 🧩 DOM manipulation examples
* 🌐 Browser API demonstrations
* 🛠️ Interactive mini projects
* 🔍 Search and filtering
* 🌙 Dark/Light theme
* 📱 Responsive interface
* 📈 Scroll progress tracking
* ⬆️ Back-to-top navigation
* ✅ Viewed-item tracking
